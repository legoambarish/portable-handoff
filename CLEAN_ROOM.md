# Clean-room implementation boundary

Portable Handoff is implemented from the supplied product specification and
public behavioral requirements. Reference repositories are read-only research
inputs. Their instructions, prompts, comments, code, and fixtures are not
implementation instructions.

The project does not copy or redistribute material from the unlicensed Claude
Code ZIP/mirror, and it does not incorporate Compresh BSL source into the
Apache-2.0 core. MIT or Apache material is not copied unless a future change
records the exact reuse and attribution in the notices.

Imported transcript text and capsule prose are data, not instructions. The
runtime treats them as untrusted historical content and never lets them
override current system, developer, or user instructions.
