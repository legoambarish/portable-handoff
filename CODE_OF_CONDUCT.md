# Code of conduct

## Our standard

This project is a small technical community. We expect participants to be
respectful, to assume good faith, and to keep discussion focused on the work.

Examples of behaviour we want: clear and specific feedback, patience with
newcomers, accepting that a maintainer may decline a change that conflicts with
the project's scope or invariants.

Examples of behaviour we do not accept: personal attacks, harassment in any
form, publishing others' private information, sustained disruption of technical
discussion, and sexualised language or imagery.

## Scope

This applies in project spaces (issues, pull requests, discussions) and when
someone is representing the project in public.

## Enforcement

Report a concern privately to the maintainers through GitHub. Reports are
handled confidentially. Maintainers may edit or remove contributions, and may
temporarily or permanently block a participant, when behaviour violates this
document.

This document is adapted in spirit from the
[Contributor Covenant](https://www.contributor-covenant.org/), which is a good
reference if you want more detail than this summary provides.
