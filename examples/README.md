# Example

One real capsule, generated by actually running the CLI against a small
repository, not hand-written. Three files, in the order they were produced:

- [`retry-fix.draft.json`](retry-fix.draft.json): what the model wrote, the
  goal, a user correction, one file reference, and one next action.
- [`retry-fix.capsule.md`](retry-fix.capsule.md): what `finalize` produced
  from that draft plus the deterministic Git facts it collected on its own
  (branch, commit, dirty state, the warning that nothing was pushed anywhere).
- [`retry-fix.briefing.md`](retry-fix.briefing.md): what `load` produces from
  the capsule, the short form a continuing session actually reads.

These are frozen output, not something you can re-validate in place. The
repository path and commit they record only ever existed in a throwaway
directory used to generate them, so running `portable-handoff validate`
against them here will fail on repository facts, not on anything wrong with
the files.

To make your own, see [Creating one](../README.md#creating-one) in the main
README.
